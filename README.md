# claude_test

## Lian-Spiel im Browser spielen

Das **Lian-Spiel** (2D-Teamkampf mit Strichmännchen) läuft direkt im Browser,
ohne Installation.

**Direkt zum Spiel:**
https://schanbacher123.github.io/claude_test/lian-spiel.html

**Übersichtsseite mit allen Projekten:**
https://schanbacher123.github.io/claude_test/

Der Link funktioniert am Computer, auf dem Tablet und auf dem Handy.

### Steuerung

**Am Computer**

| Eingabe | Aktion |
|---|---|
| Linksklick | Einheit wählen, dann Ziel oder Position anklicken |
| Rechtsklick | Direkt befehlen |
| `J` / Doppelklick | Ninja-Sprung |
| `A` | Alle angreifen |
| `G` | Rückzug |
| `Esc` | Abwählen |
| Leertaste | Pause |

**Auf Handy und Tablet**

- Einmal tippen: Einheit wählen
- Nochmal tippen: bewegen oder angreifen
- Buttons unten: Teambefehle (Angriff, Rückzug, Pause, Neustart)

### Hinweis für Entwickler

Die Seite wird über **GitHub Pages** aus dem Branch `gh-pages` veröffentlicht
(Datei `lian-spiel.html`). Änderungen am Spiel sind erst online, wenn sie in
`gh-pages` gemergt sind. Danach dauert es meist 1–2 Minuten.
